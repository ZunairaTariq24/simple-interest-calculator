# Simple Interest Calculator

This project is a simple bash script to calculate simple interest for microfinance purposes.

## Installation

1. Clone the repository:
git clone https://github.com/ZunairaTariq24/simple-interest-calculator

2. Go to the project folder:
cd simple-interest-calculator
## Usage


Run the script in terminal:

./simple-interest.sh


Follow the prompts to enter principal, rate, and time.

## Prerequisites

- Bash shell (Linux/macOS/Windows with WSL)
- No extra software required
